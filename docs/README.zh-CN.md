# ZEEHO Speed Hunter

[![GitHub License](https://img.shields.io/github/license/RyanYuFish/Zeeho-SpeedHunter?logo=gnu&logoColor=white)](https://github.com/RyanYuFish/Zeeho-SpeedHunter/blob/main/LICENSE)

面向 ZEEHO App（`com.cfmoto`）的 LSPosed 模块，用于个人设备上的兼容性研究与界面恢复。
**与 ZEEHO / CFMOTO 无任何隶属或授权关系。**

## 功能

| #    | 能力               | 说明                                                         |
| :--- | :----------------- | :----------------------------------------------------------- |
| 1    | **骑行记录恢复**   | 显示被服务端隐藏的骑行统计：骑行分析入口、极速、急加速、急刹、压弯 |
| 2    | **OTA 流量记录**   | 只读观察 OTA 链路，不伪造、不改写任何服务端数据              |
| 3    | **OTA 推送控制台** | 向仪表推送升级包，推送前强制完成六项自洽性检查，任一项不过即禁止推送 |
| 4    | **仪表壁纸推送**   | 自定义壁纸推送到仪表，支持用相册图片裁切生成壁纸包           |
| 5    | **仪表投屏**       | 将手机屏幕投到仪表，独立运行，不依赖官方 App                 |
| 6    | **车端诊断**       | 读取车辆信息、故障码、ECU、数据流等；写类操作默认禁用        |
| 7    | **网络直连与诊断** | 连接车机 Wi-Fi 并探测车机地址，供推送与诊断使用              |

## 使用前提

- 在 Xposed / LSPosed 中安装并启用模块，作用域限定为 `com.cfmoto`；
- 启用后强制停止并重开 ZEEHO App；
- 部分功能（投屏、壁纸推送）可脱离模块独立使用。

## 安全与隐私

- 不上传骑行记录、车辆信息、位置或账号数据；
- 不修改 ZEEHO APK，不绕过账号权限，不改变车辆控制逻辑；
- 速度数据仅供界面显示，不能替代仪表或作为安全决策依据；
- **请勿在骑行过程中操作手机或依赖本模块读数**；
- 刷写固件有变砖风险，推送前务必确认检查全过，并保证电量充足、非充电、非 Ready 状态；
- 日志可能包含车辆识别码、骑行记录、账号字段等个人信息，请注意保管。
